# Тропка Онлайн

Сайт для передачи файлов и текста между двумя телефонами напрямую (WebRTC), без установки и без своего сервера. Соседний проект «Тропка» (`..\Передача файлов`) — телефон↔ПК по домашней сети. Интерфейс на русском, отвечать коротко.

Хостинг: GitHub Pages (папка `docs/`, ветка main) — статика, адрес `имя.github.io/репозиторий/`. Cloudflare не используем: в России его трафик режут.

## Как работает
1. Телефон A жмёт «Создать связь»: случайные `room` и ключ AES, в QR ссылка `…/#room.key` (ключ только во фрагменте, на серверы не уходит).
2. Телефон B открывает ссылку и каждые 3 с шлёт `hello`; A отвечает `offer`, B — `answer` (SDP целиком, без trickle ICE).
3. Сообщения рукопожатия шифруются AES-GCM и идут сразу через три публичных сервера: ntfy.sh, broker.emqx.io, broker.hivemq.com (MQTT по WebSocket). Работает, пока доступен хотя бы один.
4. Дальше DataChannel: файлы кусками по 16 КБ (JSON-заголовок `file` → бинарные куски → `got`), текст `text`. STUN: Google и Cloudflare (UDP). TURN нет — через разные мобильные сети напрямую может не получиться.

## Файлы (`docs/`)
- `index.html` — экраны (старт, QR, чат, ошибка), CSP-метатег (список серверов в `connect-src`: новый сервер добавлять и туда).
- `app.js` — интерфейс, лента, отправка. `p2p.js` — `Peer`: WebRTC и протокол передачи. `signal.js` — шифрование и транспорты ntfy/MQTT.
- `qrcode.js` — qrcode-generator 1.4.4 (MIT), без изменений. `style.css` — тема как у «Тропки».

## Проверка
`python -m http.server 8765 --bind 127.0.0.1` в `docs/`, две вкладки браузера: в первой «Создать связь», ссылку взять из `#qr` `dataset.url`, во второй открыть и **перезагрузить** (смена только `#` страницу не перезапускает). Файл сверять по SHA-256 (blob-ссылку читает `fetch`, `blob:` разрешён в `connect-src`).

## Подводные камни
- Принимаемый файл целиком копится в памяти (Blob) — гигабайтные на телефоне могут не пройти.
- Свёрнутая вкладка рвёт передачу; на время связи держим Wake Lock.
- Лимит ntfy на тело сообщения 4096 байт: SDP с датаканалом (~1–2 КБ после шифрования и base64) влезает; при добавлении TURN-кандидатов следить за размером.
- Публичные брокеры не гарантированы; при пропаже одного работают остальные. Если нужен свой — добавить транспорт в `openRoom`.
- В России не проверено с мобильным интернетом и разными операторами.
